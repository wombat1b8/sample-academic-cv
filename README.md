# Sample Academic CV

A clean, single-page academic CV template (A4) built with plain HTML + print CSS — no build tools.

- `index.html` – the CV source (edit this; open in a browser)
- `cv.pdf` – pre-rendered one-page PDF

## Print / export
Open `index.html` in Chrome → Print → A4, margins *Default*, background graphics off. Or:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --no-pdf-header-footer --print-to-pdf=cv.pdf index.html
```
